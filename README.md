# PCB Laser Engraver

A custom-built PCB laser engraving machine designed for rapid PCB prototyping and simplified PCB manufacturing workflows.

The system is being developed to reduce the complexity of traditional PCB prototyping by allowing users to directly upload PCB images/designs for engraving, without requiring specialized CAM software such as CopperCAM.

# Project Objectives

- Simplify PCB prototyping workflow
- Eliminate dependency on complex CAM software
- Enable rapid PCB iteration and testing
- Reduce PCB development time
- Improve accessibility for beginners and rapid development teams
- Create a compact and low-cost PCB prototyping solution

---

# Current Features

- XY belt-driven motion system
- Laser engraving module
- Arduino + CNC Shield based control system
- GRBL firmware support
- Custom mechanical frame
- Modular electronics architecture
