# Laser Debugging

## Problem: Laser Not Turning ON

### Possible Causes
- No power supply
- PWM signal missing
- Loose wiring
- Incorrect laser polarity

### Diagnostic Steps
1. Check 12V supply voltage
2. Verify laser PWM connection
3. Test laser module independently using button on driver
4. Check connector polarity
5. Ensure that button is in ON mode (pressed) on driver module, otherwise no use!



## Problem: Laser Flickering

### Possible Causes
- Weak power supply
- Loose wiring
- PWM instability

### Fixes
- Add capacitors near supply
- Separate motor and signal wires
