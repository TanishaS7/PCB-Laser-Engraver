# Power Supply Debugging

## Problem: Machine Randomly Resets

### Possible Causes
- SMPS overload
- Voltage drop
- Loose AC connection

### Diagnostic Steps
1. Measure voltage during operation
2. Check terminal tightness
3. Verify total current draw

### Fixes
- Use higher current SMPS
- Tighten terminals
- Improve wiring

---

## Problem: Voltage Fluctuation

### Possible Causes
- Poor quality SMPS
- Overloaded supply

### Fixes
- Replace SMPS
- Add filtering capacitors
