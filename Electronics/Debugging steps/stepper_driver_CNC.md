# Driver Debugging

## Problem: Driver Overheating

### Possible Causes
- Excessive current limit
- No cooling
- Motor overload

### Diagnostic Steps
- Reduce current limit
- Add heatsink and fan



## Problem: Motor Not Moving

### Possible Causes
- Driver inserted incorrectly
- Faulty driver
- ENABLE pin issue

### Fixes
- Reinsert driver properly
- Replace driver
- Check CNC shield pins
