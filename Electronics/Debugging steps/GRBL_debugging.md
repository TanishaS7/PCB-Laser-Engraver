# GRBL Debugging

## Problem: Machine Not Connecting

### Possible Causes
- Wrong COM port
- Incorrect baud rate
- Driver issue

### Diagnostic Steps
1. Verify COM port
2. Check baud rate
3. Restart controller


## Problem: Incorrect Movement Distance

### Possible Causes
- Wrong steps/mm
- Belt slipping

### Fixes
- Calibrate steps/mm
- Adjust belt tension



## Problem: Alarm Errors

### Possible Causes
- Homing issue
- Limit switch noise

### Fixes
- Disable homing temporarily
- Add pull-up resistors
